feat: add bound_filter param to vmap functions; change only_bound default

firebox_vmap now accepts a bound_filter argument ('none', 'only_sats',
'all') that controls whether load_particles filters to bound members,
and encodes that choice in the output directory name so runs with
different filters don't overwrite each other. The only_bound default in
load_particles changes from True to False. imshow_firebox_vmap gains
interpolation='nearest' and the seismic_r colormap to fix sparse-dot
appearance. calc_vmap and firebox_vmap docstrings clarify imshow vs
pcolormesh orientation behavior.
